# Cinematic Love Story — Birthday Website (Next.js 14 App Router)

    npm install
    npm run dev      # http://localhost:3000
    npm run lint && npm run build

Edit semua konten di `content/config.ts`. Foto → `public/photos/`, musik → `public/audio/`
(lalu isi path-nya di config, mis. `/photos/1.jpg`, `/audio/song.mp3`).
Struktur: `app/` (layout, page), `sections/` (7 chapter), `components/` (FX, Reveal, Chrome), `content/`, `lib/`.
